# DevMagic Panel docs

The [README](../README.md) is the short tour. These pages hold the detail.

## Getting started

- [Installation and uninstall](installation.md): where the package comes from,
  the installer's options, what it does step by step, and what an uninstall
  removes, asks about and keeps.
- [Living with your existing setup](existing-setup.md): what the panel changes
  and what it leaves alone, from vhosts and hosts lines to the two files it
  adds to a site.

## Using the panel

- [Sites](sites.md): the Sites page, a site's page and its tabs, quick actions,
  and sites under a path.
- [New site](new-site.md): a project's repos and where each goes, Claude Code
  as an option, where the dump comes from, and install drafts.
- [Files](files.md): a site's folder and files, what opens here and what stays
  out of reach
- [Databases](databases.md): tables and rows, WordPress clean-ups, the SQL
  runner, exports and imports, and what each change saves first.
- [Services](services.md): PHP, MySQL, Apache, nginx and cron.
- [Other pages](pages.md): the menu, Aura and its machine checks, WP Cores,
  Mail, Settings, Activity, removed sites and Developer options.
- [AI assistant](ai-assistant.md): the briefing, the chat, the wizard's
  helper and the MCP server.

## Keeping it running

- [Undo and backups](undo-and-backups.md): `dmp-restore` and every Undo inside
  the panel.
- [Updates](updates.md): where releases come from, how an update installs, and
  going back.
- [How it stays safe](security.md): localhost only, root through `dmp-root`,
  local names, secrets and checked packages.
- [Troubleshooting](troubleshooting.md): certificates, the service, ports,
  MySQL, mail, apt and logs.
